# Oblik OS application design

Light product interface using existing tokens in src/app/globals.css.
Manrope Variable carries headings and body text. Canvas #ffffff, surfaces
#f7f8f6, text #252b28, muted #657069, accent #2f5141, borders #e5e8e3.
Use existing Card, Button, form-field, character-fields and form-message components.
Desktop forms use two columns; mobile forms stack with explicit labels.
Tabs and progress steps wrap on small screens. Voice previews use native audio
controls and explicit paid-action buttons. Preserve current product styling.
