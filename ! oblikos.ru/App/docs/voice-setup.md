# Голос персонажа

## Qwen3-TTS: локальное подключение и проба

В поле «Сервис озвучки» доступен Qwen. Используется фиксированная модель
`qwen3-tts-instruct-flash-2026-01-26`, русский язык, готовые голоса
Cherry, Serena, Ethan, Chelsie, Kai и Maia. Создание голоса по описанию и клонирование
в этой интеграции пока не реализованы.

1. Зарегистрируйтесь в Alibaba Cloud: https://www.alibabacloud.com/.
2. Активируйте Model Studio и выберите регион Singapore.
3. Создайте API-ключ этого региона по инструкции:
   https://www.alibabacloud.com/help/en/model-studio/get-api-key.
4. Добавьте ключ в локальный `.env`: `DASHSCOPE_API_KEY=ваш_ключ`.
   Не отправляйте ключ в чат и не коммитьте файл.
5. Перезапустите `npm run dev`. Откройте персонажа → Голос →
   Сервис озвучки → Qwen. Выберите Serena или Kai и нажмите «Послушать голос».
6. Сравните Qwen и OpenAI на одном русском тексте. Сохраните настройки,
   если голос подходит персонажу.

Темп задаётся инструкцией, поэтому числовое изменение скорости не гарантируется.
Стандартная манера речи автоматически описывается на английском. Дополнительные
пожелания Qwen поддерживает на английском или китайском; в этой форме рекомендуем
английский. Кириллица в пожеланиях отклоняется до обращения к сервису.
Текст озвучки остаётся русским.

Ключ доступен только серверу. Готовый WAV скачивается в существующее приватное
хранилище проб в БД; браузер получает его через `/api/voice/[id]`, без внешних
ссылок и ключа. Формат WAV/MP3 определяется по файлу. Действуют существующие
лимиты, срок хранения сутки и защита UUID от повторного платного запроса.
При ошибке Qwen приложение не переключается автоматически на платный OpenAI.
Новая схема БД и миграция для добавления Qwen не требуются.

Без `DASHSCOPE_API_KEY` можно сохранить выбор, но реальная генерация недоступна.
Автоматические проверки `npm run test:qwen` используют подставленные HTTP-ответы
и не проверяют звучание, доступность аккаунта или списание средств.

Источники: https://www.alibabacloud.com/help/en/model-studio/qwen-tts-api,
https://www.alibabacloud.com/help/en/model-studio/qwen-tts-voice-list.

## OpenAI и общие настройки

Создание: Идентичность → Внешность → Личность → Голос → Проверка.
У существующего персонажа настройки доступны во вкладке «Голос».
Голос, темп, манера речи и пожелания сохраняются вместе с персонажем и копируются
при дублировании. Старым персонажам форма предлагает Coral и обычный темп;
после сохранения настройки становятся явной частью профиля.

Пробная озвучка (до 600 символов) через ProxyAPI /v1/audio/speech,
модель openai/gpt-4o-mini-tts, русский язык, MP3. Реальный запрос с Coral
проверен 6 октября 2026; артефакт voice-live-20261006-confirmed.json.
Другие голоса взяты из официального списка модели, отдельно живыми запросами
не проверялись. Звук искусственно создан; это указано рядом с пробой.

Используется серверный OPENAI_API_KEY и фиксированный адрес api.proxyapi.ru.
Дополнительный аккаунт и новый ключ не нужны. Видеоролики Kling по-прежнему
создаются без аудио: синхронизация губ и озвучка готового видео пока не реализованы.

## Обновление сервера

Перед публикацией сохранить резервную копию БД. Новая миграция
20261006150000_character_voice добавляет Character.voice и VoicePreview.
Обычный npm run deploy останавливается при изменении Prisma — он не применяет
миграции автоматически. Сначала отдельно примените эту добавляющую миграцию
через npx prisma migrate deploy с production.env на сервере и обновите каталог
prisma в текущем релизе до этой версии; затем выполняйте обычное обновление.
До отдельного обновления базы запуск новой версии приложения невозможен.
Проверьте наличие OPENAI_API_KEY и AI_GENERATION_ENABLED=true на сервере.
Необязательные настройки (значения по умолчанию):

```dotenv
VOICE_GENERATION_ENABLED=true
AI_VOICE_PER_MINUTE=3
AI_VOICE_PER_DAY=20
AI_VOICE_GLOBAL_PER_DAY=100
```

Настройки пользователя не запускают платный запрос. Кнопка «Послушать голос»
запускает одну платную пробу; готовый образец повторно прослушивается бесплатно.
Receipt UUID защищает повторный запрос от повторной оплаты, включая разные процессы.
Образцы доступны только создавшему пользователю в текущем workspace, максимум сутки.
Истёкшие байты очищаются npm run auth:cleanup (обычная задача обслуживания) и при
новой пробе этого пользователя. Tombstone receipts остаются для защиты от повтора.
При падении процесса во время запроса результат может остаться неизвестным;
повтор того же UUID не вызывает сервис заново.

Источники: https://proxyapi.ru/docs/text-to-speech и
https://developers.openai.com/api/docs/guides/text-to-speech.

## Qwen Flash через AITUNNEL
Серверный ключ: AITUNNEL_API_KEY в .env. В форме выберите «Qwen Flash · AITUNNEL».
Модель qwen-audio-3.0-tts-flash, голоса loongjohn и longanhuan_v3.6. Формат MP3.
Темп, манера и пожелания этой интеграцией не передаются: API не документирует их поддержку для Qwen Flash.
OpenAI продолжает использовать ProxyAPI; старые голоса Qwen3-TTS — Alibaba Cloud.
Каталог: https://api.aitunnel.ru/public/aitunnel/models/speech
Документация: https://aitunnel.ru/docs/text-to-speech

## Gemini Flash Lite через AITUNNEL
Модель gemini-3.8-flash-lite-tts, 30 голосов; по умолчанию при выборе сервиса Kore.
Использует AITUNNEL_API_KEY. PCM 24 кГц mono 16-bit преобразуется в WAV для приватного плеера.
Темп, манера и пожелания отключены: передача speech_metadata через AITUNNEL не подтверждена.
Текст отправляется без добавления инструкций, которые модель может прочитать вслух.
https://ai.google.dev/gemini-api/docs/speech-generation

## Gemini 3.1 Flash: настройка подачи
Отдельный сервис «Gemini 3.1 Flash · настройка подачи», модель gemini-3.1-flash-tts-preview.
30 голосов с префиксом gemini31:, тот же AITUNNEL_API_KEY, PCM преобразуется в WAV.
Темп, манера и пожелания превращаются в DIRECTOR'S NOTES перед TRANSCRIPT в input.
Модель получает указание читать только русский текст TRANSCRIPT. Числовой speed не передаётся:
медленный/обычный/быстрый — пожелания к подаче, а не гарантированный коэффициент скорости.
В двух живых пробах 2026-10-06 одинаковый текст с Kore занял 10,04 с (медленно/спокойно)
и 5,04 с (быстро/энергично). Это демонстрация изменения подачи, не гарантия для каждого текста.
Документация AITUNNEL: https://aitunnel.ru/docs/text-to-speech

## Подача конкретного контента
Character.voice хранит базовый голос и подачу по умолчанию.
Content.voiceOverride хранит только speed/style/instructions; пустой объект означает наследование
актуальных настроек персонажа. Индивидуальная подача не меняет Character.voice и сохраняется
при повторной генерации текста. Сброс возвращает наследование. VoiceId нельзя переопределить.
В карточке контента доступны сохранение подачи и платная проба озвучки текста (до 600 символов).
Проба использует существующий receipt-механизм защиты от повторного списания.
Автоматическое добавление этой озвучки в видео пока отсутствует.

## Бесплатная библиотека примеров Gemini 3.1
У всех 30 голосов есть готовые WAV в public/media/voice-samples.
Каталог: src/features/voice/samples.ts и generated-samples.ts.
Файлы доступны без авторизации; воспроизведение не обращается к AITUNNEL.
29 новых образцов созданы 2026-10-06 за 32,8542 ₽; Kore использует предыдущие записи.
Текст новых образцов: «Привет! Рад знакомству. Послушай, как звучит мой голос: спокойно, ясно и естественно.»
Скрипт scripts/generate-voice-library.ts пропускает записанные receipts и не повторяет неясные запросы.
Эта библиотека относится к Gemini 3.1; примеры других моделей не подменяются её записями.

## Упрощённый выбор голоса
В форме профиля доступен только Gemini 3.1, выбор сервиса скрыт.
«Тип голоса» фильтрует 14 женских и 16 мужских голосов по таблице Google:
https://docs.cloud.google.com/text-to-speech/docs/gemini-tts#voice_options
Фильтр не связан с полом персонажа. Переключение типа выбирает Kore или Orus.
Старые провайдеры сохранены для совместимости существующих записей; открытие формы
профиля предлагает эквивалент Gemini 3.1 либо Kore, изменение сохраняется пользователем.
ageTone — необязательное original/young/older, передаётся как пожелание в director's notes.
Это не возраст диктора и не гарантированная смена тембра; бесплатные примеры не меняются.
Возрастную подачу также можно переопределить в контенте, сохраняя профиль персонажа.
