# Генерация персонажей: Nano Banana 2

Локальная модель изображений: `google/gemini-3.1-flash-image` (Nano Banana 2), через существующий ключ ProxyAPI. Текстовая модель и анализ фото не меняются.

Настройки `.env` на каждой среде:

```dotenv
OPENAI_BASE_URL=https://api.proxyapi.ru/v1
OPENAI_IMAGE_MODEL=google/gemini-3.1-flash-image
OPENAI_IMAGE_REFERENCE_SUPPORTED=true
```

Адаптер в `src/features/ai/image-provider.ts` использует установленный Google SDK, нативный `/v1beta/models/gemini-3.1-flash-image:generateContent`, размер 1K и точное соотношение сторон из формы. Фото передаются inline; первое — основной референс. Повторные платные запросы автоматически не выполняются. Защита маршрутов, квоты и приватное хранение остаются в общем сервисе медиа. Прежние модели OpenAI продолжают использовать существующие Images API.

Общий промпт расположен в `src/features/ai/visual-context.ts`: естественная текстура кожи, небольшие возрастные несовершенства, натуральные волосы, пропорции, отсутствие сглаживания кожи и бьюти-ретуши. По умолчанию — мягкий дневной свет; явные пожелания пользователя о сцене и освещении сохраняются. Все фото служат референсами одного персонажа, фон референсов не копируется.

Для production нужно изменить переменные серверной среды и развернуть код; локальная `.env` не является подтверждением настройки сервера. Проверка без платной генерации: `node --conditions=react-server --import=tsx --test tests/nano-banana.test.ts`. Реализм и точность сходства требуют отдельной проверки настоящих результатов.

Документация API: https://proxyapi.ru/docs/gemini-api
