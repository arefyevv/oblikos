# Говорящее видео персонажа

Реализовано 7 октября 2026 года. Раздел: персонаж → «Медиа» → «Создать говорящее видео».

## Как пользоваться

1. Создать персонажа и открыть его медиатеку.
2. Во вкладке «Голос» выбрать голос и подачу.
3. В «Медиа» открыть «Создать говорящее видео». Выбрать исходное фото из существующих либо открыть «Создать новый образ», описать одежду, место и детали, сгенерировать фото и подтвердить его кнопкой «Использовать этот образ для видео». Новое фото сохраняется в медиатеке. Основной образ персонажа не меняется. Создание фото оплачивается отдельно и не запускает озвучку или видео.
4. Ввести текст (до 600 символов), выбрать формат и максимальную длительность 15, 30 или 60 секунд. Нажать «Создать видео с речью». Сервис создаёт озвучку выбранным голосом, затем передаёт выбранное фото и аудио в HeyGen Avatar IV через AITUNNEL. Поле «Пожелания к движению» задаёт жесты и мимику; одежда, фон и предметы берутся из фото.
5. Дождаться результата в медиатеке. Статус сохраняется в БД; страницу можно перезагрузить. Готовое видео сохраняется при очередной проверке статуса, в том числе после возвращения в медиатеку. Отдельного фонового worker нет.

Выход: MP4 с речью, 720p, 9:16 / 16:9 / 1:1. Обычная генерация видео Kling остаётся отдельной функцией.

## Настройка сервера

В `/etc/oblikos/production.env` должен быть действующий `AITUNNEL_API_KEY`. Также нужны настройки провайдера выбранного голоса: существующие голоса OpenAI используют ProxyAPI, Gemini/Qwen используют свои текущие настройки. Ключи остаются на сервере.

Из каталога приложения выполнить `npm run deploy`. Локальный `.env` скрипт не переносит. Изменения этой задачи локально собраны и проверены; production-деплой этой задачи не выполнялся.

По каталогу AITUNNEL на дату проверки видео стоит 8,50 ₽/сек; озвучка оплачивается отдельно. Фактическая длительность определяется аудио. Приложение выбирает минимальную поддерживаемую длительность, вмещающую речь и не превышающую выбранный лимит. Если речь не помещается, платный запрос видео не отправляется, но подготовленная озвучка уже оплачена. Тариф может измениться.

Источники: [API видео AITUNNEL](https://aitunnel.ru/docs/videos), [каталог моделей](https://api.aitunnel.ru/public/aitunnel/models/videos).

## Архитектура и защита

- `src/features/ai/avatar-provider.ts`: провайдер `aitunnel-avatar`, модель `avatar-iv`; асинхронный API видео. Передаёт приватные портрет и аудио как data URL, без публичного открытия локального хранилища. Не передаёт `generate_audio`: используется готовая речь.
- `src/features/media/video-service.ts`: соединяет существующий сервис голосов и генерацию видео. `music-metadata` определяет длительность WAV/MP3. Провайдер статуса выбирается по сохранённой модели задания.
- `video-operations.ts`: повторно использует `MediaGeneration`, `VoicePreview`, `MediaAsset`, ограничения генераций и изоляцию рабочих пространств. Миграция БД не требуется. После подготовки речи доступ к персонажу и портрету проверяется повторно.
- `talking-form.tsx`, `video-actions.ts`, `visual-identity.tsx`: форма в медиатеке персонажа, серверное действие и подключение к существующему интерфейсу. Для интервалов и адаптивности используются существующие классы и токены.
- `video-validation.ts`, `video-types.ts`, `video-file.ts`: отдельная валидация речи, ошибки озвучки/длительности, проверка длительности MP4 до 61 секунды только для Avatar IV. Перед сохранением обязательно проверяется наличие звуковой дорожки.
- UUID запроса хранится в браузере и БД. Повтор той же отправки не запускает новую платную генерацию или озвучку. При неоднозначном ответе провайдера автоматического повторного POST нет. Новая попытка после однозначного отказа запускается пользователем явно.
- Скачивание использует только фиксированный адрес API с серверной авторизацией; URL из ответа провайдера игнорируются. Файлы выдаются существующим приватным маршрутом `/api/media/[id]` с проверкой доступа.

## Проверки

- Реальный одиночный запрос Avatar IV: готовый ролик 4,03 сек, 1 531 612 байт, H.264 и AAC, стоимость 34 ₽. Исходники: публичный демонстрационный портрет и обрезанный публичный голосовой пример. Контейнер проверен на наличие аудио и видео; субъективное качество произношения и синхронизации требует просмотра ролика. Артефакт: `artifacts/avatar-live-20261007.mp4`.
- `npm run test:avatar`: 17 offline/integration проверок — API, фото + аудио, ошибки, отсутствие платных автоповторов, доступ рабочих пространств, повторные отправки, превышение длительности, сохранение и восстановление готового результата. Включает регрессионные проверки обычного видео.
- Playwright: изолированный аккаунт, основной образ, голос, отправка, перезагрузка, приватное воспроизведение, отсутствие доступа без авторизации и отсутствие горизонтального overflow на 1440/390 px. AI API подменены; браузерные тесты не расходуют баланс.
- Typecheck, lint, production build проходят.

## Следующий этап

### Выбор образа, 9 октября 2026

- Общий `video-reference-picker.tsx` подключён к обычному и говорящему видео, в том числе в разделе создания контента. Фото загружаются отдельно от фильтра основной галереи, с пагинацией. Выбор, описание нового образа и неподтверждённый предпросмотр восстанавливаются после перезагрузки текущей вкладки.
- `video-reference-actions.ts` выдаёт только ID, дату и признак основного фото в рамках текущего пользователя и персонажа. Для предпросмотра используются существующие приватные `/api/media/[id]`.
- Необязательный `referenceAssetId` в запросе видео выбирает конкретное фото. Запросы старого формата сохраняют выбор основного референса по умолчанию. ID включён в fingerprint, проверяется до озвучки и платного API и сохраняется в задании и готовом ролике. Чужие, удалённые изображения и видео вместо фото отклоняются. Выбранное фото нельзя удалить во время активной генерации.
- Новый образ создаётся существующим сервисом изображений. UUID запроса сохраняется в браузере, повтор после потери ответа проверяет прежний запрос. Для новой попытки после окончательной ошибки предусмотрена отдельная кнопка. Подтверждение фото включает кнопку создания видео, но само не запускает платное видео.
- Проверки: `test:avatar` (18 тестов), Playwright `talking-video.spec.ts` и `video.spec.ts` (2 сценария), typecheck, lint, production build. Браузерная проверка включает новый образ, подтверждение, отсутствие видео и озвучки до подтверждения, выбор другого фото, сохранение основного образа, перезагрузку и адаптивность 1440/390 px. AI-провайдеры подменены. Публикация на production в рамках этого изменения не выполнялась.
