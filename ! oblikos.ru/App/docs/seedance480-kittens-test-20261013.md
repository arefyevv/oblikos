# Seedance Mini 480p: тест котят, 13 октября 2026

Виктор разрешил один тест 5 секунд, затем явно разрешил одну дополнительную
попытку сверх суточного ограничения. Постоянные настройки сервиса не менялись.

- Модель: `seedance-2.0-mini`, AITUNNEL.
- Запрос: `480x854`, 5 секунд, исходное видео и прежнее фото трёх котят.
- Задание: `a18feea9-cb6d-4e7f-b9a0-82495576a87f`.
- Provider job: `vid_fb326bc72bbe4c29bfd65c5062d5f77e`.
- Медиа: `8e876118-6cf5-49fd-abdd-9bbb01b07d9c`.
- Подтверждённое `usage.cost_rub`: **28.5823125 ₽**.
- Полученный файл: 496×864, 5.042 секунды, исходная аудиодорожка возвращена
  существующим `restoreOriginalVideoSound` перед сохранением в медиатеку.
- Локальный результат: `output/seedance480-kittens-20261013.mp4` от корня проекта.

Визуальная проверка пяти кадров с интервалом 1 секунда: три человека остались
в кадре; модель добавила двух котят у ног, вместо замены трёх людей котятами.
Этот тест **не выполнил задачу**. Он подтверждает работоспособность API и цену,
но не качество переноса движений, липсинка или соответствие котят фотографии.
Считать модель подходящей для данного сценария по этому результату нельзя.

Две предыдущие локальные попытки подготовки не вызвали платного API:
`29f5ca90-4058-4e2b-92d5-a190e3dd78b9` остановилась на HEAD-проверке исходника
(создан от root, приложение не могло читать файл с правами 600);
`171f50d3-69ea-4620-8d50-601d011e8f65` остановилась на суточном ограничителе.
Оплаченный запуск выполнен от пользователя `oblikos` с `AI_VIDEO_PER_DAY=11`
только в окружении процесса теста. Автоматических повторов POST нет.

Проверки скриптов: ESLint и TypeScript прошли. Тестовая выдача не добавляет
выбор 480p в пользовательский интерфейс и не переключает production-модель.
