# Видео персонажа через Kling 3.0 Pro

Подключение проверено 6 октября 2026: один live запрос с приватным основным
портретом вернул HTTP 202, задание завершилось READY, MP4 сохранён в медиатеку.
Артефакт проверки: `artifacts/kling-live-20261006.json`. Других платных Kling
create в этой проверке не выполнялось. В браузере проверены воспроизведение и
первый/последний кадры: персонаж поворачивается и улыбается, внешность узнаваема.
Сохранение лица не гарантируется для любых сцен.

## Настройка

Локально модель уже выбрана в `.env`. На VPS в `/etc/oblikos/production.env`:

```dotenv
OPENAI_BASE_URL=https://api.proxyapi.ru/v1
OPENAI_VIDEO_MODEL=kwaivgi/kling-v3.0-pro
VIDEO_GENERATION_ENABLED=true
AI_VIDEO_PER_MINUTE=1
AI_VIDEO_PER_DAY=5
AI_VIDEO_GLOBAL_PER_DAY=20
```

Используется существующий `OPENAI_API_KEY`. `AI_GENERATION_ENABLED` также должен
быть true. API-ключ остаётся на сервере. Миграции и новые зависимости не нужны.
Выложите обновлённое приложение командой `npm run deploy` из папки `App`.
Скрипт deploy не меняет production.env: модель нужно изменить на сервере отдельно.
После изменения env перезапустите службу: `systemctl restart oblikos`.

## Пользовательский сценарий

Персонаж → Внешность → сгенерировать фото → выбрать основной образ → Создать видео
→ описать сцену и движение → выбрать 3/4/6/8 секунд и формат → Сгенерировать видео.
В запросе используется 720p, без аудио. В реальной проверке сервис вернул
1080×1080 и 4,04 секунды, несмотря на запрос 16:9: пропорции повторили портрет.
Интерфейс предупреждает, что выбранный формат может не соблюдаться.
Работа начинается от основного портрета; его приватные байты
передаются в frame_images с frame_type=first_frame как data URL. Публичной ссылки
на защищённое изображение не создаётся.

Статус и идентификатор задания сохраняются до перезагрузки. Готовое видео
автоматически сохраняется в приватное хранилище и связано с исходным портретом.
Повторный submit с тем же UUID не создаёт новую платную генерацию. При лимите,
выключенной генерации или ошибке проверок платный вызов не выполняется.

По опубликованному тарифу 15,79 ₽/с четырёхсекундный ролик стоит 63,16 ₽;
фактическое списание отдельно не проверено. Не включайте видео в безлимитный тариф.
