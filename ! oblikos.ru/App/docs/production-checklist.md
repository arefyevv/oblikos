- [ ] DATABASE_URL и Compose credentials соответствуют
- [ ] validate / migrate deploy / status / drift / db:check пройдены

- [ ] При обновлении POSTGRES_VOLUME_NAME указывает на существующий том, БД и media сохранены
- [ ] Nginx -t; forwarded headers заменяются; AUTH_TRUST_PROXY=true

- [ ] MEDIA_STORAGE_DIR absolute вне releases, owner/permissions, без symlink
- [ ] media пережила build/restart/VPS reboot и protected GET/Range работает
- [ ] ProxyAPI key/text/image model/endpoint заданы и проверены
- [ ] AI user/workspace/global ceilings приняты оператором
- [ ] Kill switches проверены, после env change restart
- [ ] Email flows disabled; участники знают, что reset ещё недоступен

- [ ] Video create disabled, отсутствует работающая CTA генерации
- [ ] lint/typecheck/build/integration/full E2E/production E2E passed locally

- [ ] Daily DB+media backup, независимая копия, restore drill выполнен
