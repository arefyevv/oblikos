# Обложки блога

Повторно используются утверждённые изображения цифровых персонажей из
`Site/src/assets/photos/`. Источник и исходные промпты описаны в README этой папки.
Фотографии созданы с помощью image_gen. Это иллюстрации, а не фотографии реальных клиентов.
`logo.svg` — копия существующего логотипа приложения для публичного пути `/blog/media/`.
